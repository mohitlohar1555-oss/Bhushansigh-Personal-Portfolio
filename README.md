# Bhushansigh Girase – Portfolio Website

A responsive personal portfolio website for Bhushansigh Girase, a B.Pharm graduate and owner of Swami Medical, Mod.

## Files
- `index.html` – Website structure and content
- `style.css` – Responsive design and styling
- `script.js` – Mobile navigation and current year

## Run locally
1. Extract the ZIP file.
2. Open the `index.html` file in any modern browser.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Customize before publishing
- Confirm the spelling of the name and college details.
- Verify the listed skills match your actual knowledge.
- Replace the sample academic project ideas with your real completed projects.
- Add a professional email address and LinkedIn profile if available.


## Business experience
The portfolio includes an owner/business experience section for Swami Medical, Mod. Verify the business description and listed responsibilities before publishing.
